# Split Trip
A phone-first classroom MVP for planning group trips and funding each traveler's share before booking.

## Try the demo
Open index.html in a browser. No installation or build is required.

- Create a trip with friends and travel dates.
- Add costs and split amounts equally, down to the cent.
- Vote on a travel style and save budget preferences.
- Set a funding deadline and preview reminders.
- Simulate individual contributions, then unlock the demo booking.
- See the shared itinerary and reset the sample trip.

## Demo scope
Payments, bookings, reminders, and sample travel options are simulations. No money is collected or held, no messages are sent, and no vendor is contacted. Data is stored in each visitor's browser and does not synchronize between visitors. Votes do not change the budget.

## GitHub Pages
In repository Settings → Pages, select “Deploy from a branch”, then the main branch and /(root). Save to publish the app.
